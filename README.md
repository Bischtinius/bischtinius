## 🧑‍💻 About Me

I'm an embedded systems engineer with a background in mechanical engineering and robotics.

Working close to hardware, from microcontrollers to robotic systems, is what I enjoy most, especially when the results of my code are visible in the physical world.

I like understanding how things work, improving existing systems, and contributing to free and open-source software.
